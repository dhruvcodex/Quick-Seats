📌 QuickSeats – Integrated Bus Ticket Booking Platform
An efficient, scalable, and secure full-stack Java web application that streamlines the process of booking bus tickets, connecting passengers with local travel agencies.

🚀 Problem Statement
The traditional bus ticketing systems are plagued by:

Manual bookings prone to error and delays

Lack of real-time updates and passenger communication

Limited digital reach for local travel agencies

Inefficient data management and scaling challenges

✅ Solution – QuickSeats
QuickSeats offers a modern digital platform that allows:

Passengers to search, book, cancel, and manage bus tickets easily.

Agencies to register, add buses, manage bookings, and communicate securely with users.

Admins to verify and authorize agency activities.

A real-time data-backed platform with secure authentication and simplified user interfaces.

💻 Tech Stack
Layer	Technologies Used
Frontend	HTML, CSS, JavaScript
Backend	Java, Servlets, JSP, Spring Boot
Database	MySQL
IDE	NetBeans 8.2
Tools	Git, GitHub (Version Control), Tomcat
Security	Session Management, Server-side Auth
🧠 Key Features
🚌 Bus Booking System: Browse routes, check availability, book or cancel in real time.

🔐 User Authentication: Role-based access for users, agencies, and admins.

🧾 Agency Dashboard: Manage fleet, bookings, and customer inquiries securely.

📬 Secure Communication: In-app messaging between users and agencies.

📊 Admin Panel: Manage agencies and monitor system data.

📧 Email Verification: Verify user/agency via mail on registration.

📱 Mobile-Responsive UI: Optimized for devices of all sizes.

🧪 Testing
Tested using Black Box Testing methodology.

Test Case 1 – Verifies successful login and user data fetch
Test Case 2 – Verifies data insertion and retrieval in MySQL database
✅ All critical components passed functional and integration tests.

📈 Future Enhancements

📂 How to Run
Clone this repository

Import into NetBeans 8.2

Set up the MySQL database using provided SQL scripts

Configure Tomcat Server

Run the application and navigate to localhost:8080/QuickSeats
